# 執筆マニュアル

この記事を見れば、エンジニアニメの原稿を執筆し、本として形にするまでの流れがわかります。
わからないことがあれば、気兼ねなくオクラまでお尋ねください。

## ざっくりとやること

### Git操作に不慣れな方

このテンプレートではGit操作に慣れている方向けの手順を主としていますが、Git操作に不慣れでも記事を作成いただけます。
その場合は、オクラまで個別にご連絡いただけると幸いです。

### Git操作ができる方

1. リポジトリに招待してもらう
2. GitHub上にIssueを作成し、考えているタイトルやページ数などを表明する
3. 自分の作業用ブランチを作成する
4. 記事を作成する
5. リモートリポジトリにPushする
6. 作業ブランチから `main` ブランチに対してPull Requestを作成する
7. `main` ブランチにマージする

---

## 各ステップの詳細

### 1. リポジトリに招待してもらう
うーたんさん、またはオクラに Discord でメンションしてください。

### 2. Issueを立てる
- リポジトリの **Issues** タブを開く
- **New Issue** をクリック
- 「章の提案」を選択し、テンプレートに従って内容を埋めてください。

### 3. 記事を作成する
`book/manuscripts/` ディレクトリに、 `<記事の概要>_<あなたの名前>.md` の形式でファイルを追加してください。
例: `kanata_no_astra_ohkura.md`

ファイルを追加すると、自動的に本の章として登録されます（`index.md` など固定のファイルを除き、ファイル名順に並びます）。作成後、自分の作業ブランチをリモートリポジトリにPushしてください。

### 4. 生成されるPDFを確認する
Pull Requestを通して確認する方法と、ローカルで確認する方法があります。

#### Pull Requestで確認する
`main` ブランチに対してPull Requestを作成すると、GitHub Actionsにより自動的にPDFが生成されます。
しばらくするとPRにコメントがつき、そこからPDFをダウンロードして確認できます。

#### ローカルで確認する
Node.js環境がある場合は、以下のコマンドでPDFを作成できます。

```shell
# 依存関係のインストール
yarn install

# ビルド（macOSの場合、brew install ghostscript xpdf が必要です）
yarn start
```

### 5. mainブランチにマージする
セルフチェックが済み、問題なければ `main` ブランチにマージしてください。
※誰かのApproveを待つ必要はありません。入稿前に全体で改めて相互レビューを行います。

## よくある質問（Q&A）

### Q. 画像を入れたい場合はどうすればいいですか？
`book/manuscripts/` 配下に `images_<あなたの名前>` というフォルダを作成し、その中に画像を入れてください。

### Q. Git操作やGitHubの使い方がわかりません
気兼ねなくオクラまでお尋ねください！
