# 執筆マニュアル

この記事を見れば、エンジニアニメの原稿を執筆し、本として形にするまでの流れがわかります。
わからないことがあれば、気兼ねなくオクラまでお尋ねください。

## ざっくりとやること

### Git操作に不慣れな方

このテンプレートではGit操作に慣れている方向けの手順を主としていますが、Git操作に不慣れでも記事を作成いただけます。
その場合は、オクラまで個別にご連絡いただけると幸いです。

### Git操作ができる方

1. リポジトリに招待してもらう
2. GitHub上にIssueを作成し、考えているタイトルやページ数などを表明する
3. 自分の作業用ブランチを作成する
4. 記事を作成する
5. **[book/manuscripts/book.json](../book/manuscripts/book.json)** に記事情報と著者情報を登録する
6. `yarn start`（または `yarn sync`）を実行して、設定を各ファイルに反映させる
7. リモートリポジトリにPushする
8. 作業ブランチから `main` ブランチに対してPull Requestを作成する
9. `main` ブランチにマージする

## 各ステップの詳細

### 1. リポジトリに招待してもらう
うーたんさん、またはオクラに Discord でメンションしてください。

### 2. Issueを立てる
- リポジトリの **Issues** タブを開く
- **New Issue** をクリック
- 「章の提案」を選択し、テンプレートに従って内容を埋めてください。

### 3. 記事を作成する
`book/manuscripts/` ディレクトリにある **`sample_chapter.md` をコピーして**、 `<記事の概要>_<あなたの名前>.md` の形式でファイルを作成し、執筆を開始してください。
例: `kanata_no_astra_ohkura.md`

※コピーしたファイルの冒頭にあるテンプレート（タイトルや著者名のプレースホルダ）は、後のステップで自動的に書き換えられます。

### 4. 記事情報と著者情報を登録する
`book/manuscripts/book.json` に自分と記事の情報を追加してください。

- **アイコン画像**: `book/manuscripts/images_authors/` フォルダの中に、自分のアイコン画像を配置してください。ファイル名は `<ユーザー名>.<拡張子>`（例: `ohkura.png`）としてください。
- **設定値**: `book.json` の `icon` フィールドには、**パスを含まないファイル名のみ**（例: `ohkura.png`）を記述してください。
- **Discord**: Discordのユーザー名を記載してください。これは主催者からの連絡や、進捗確認などの円滑なコミュニケーションのために使用します（**本には掲載されません**）。
- **反映**: ここに登録された情報をもとに、目次、PDFの構成（章の順番）、著者紹介ページ、および各原稿内のタイトル・著者名が自動生成・同期されます。

```json
{
  "name": "名前",
  "icon": "ユーザー名.拡張子",
  "x": "@TwitterID",
  "discord": "Discordのメンション名",
  "job": "職業/肩書き",
  "favorites": ["好きなアニメ1", "好きなアニメ2"],
  "articles": [
    {
      "title": "記事のタイトル",
      "file": "作成したファイル名.md"
    }
  ]
}
```

### 5. 生成されるPDFを確認する
Pull Requestを通して確認する方法と、ローカルで確認する方法があります。

#### Pull Requestで確認する
`main` ブランチに対してPull Requestを作成すると、GitHub Actionsにより自動的にPDFが生成されます。
しばらくするとPRにコメントがつき、そこからPDFをダウンロードして確認できます。

#### ローカルで確認する
Node.js環境がある場合は、以下のコマンドで同期とPDF作成ができます。

```shell
# 依存関係のインストール (初回のみ)
yarn install

# 同期・ビルド・PDF表示（すべて一括）
yarn start
```

## よくある質問（Q&A）

### Q. 画像を入れたい場合はどうすればいいですか？
`book/manuscripts/` 配下に `images_<あなたの名前>` というフォルダを作成し、その中に画像を入れてください（例: `images_ohkura/my_image.png`）。
Markdownからの参照は、その相対パス（`![画像名](images_ohkura/my_image.png)`）で記述してください。

### Q. 見出しや著者名が古いままです
`yarn sync`（または `yarn start`）を実行してください。`book.json` の内容が各ファイルに反映されます。
※内部的には `.sync-state.json` というファイルで差分を管理していますが、これはGit管理外なので気にする必要はありません。

### Q. Git操作やGitHubの使い方がわかりません
気兼ねなくオクラまでお尋ねください！
