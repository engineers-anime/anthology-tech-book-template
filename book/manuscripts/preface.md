# まえがき

私たちは、アニメというエンターテインメントからエンジニアとしての気づきや学びをみつけ、それを共有したいという思いで集まりました。本書では、多くの方々が「アニメから得た学び」をテーマに綴っています。

本書の執筆は、エンジニアニメというコミュニティーが主催する「アニメから得た学びを発表会」から始まりました。エンジニアニメは、アニメやラノベ好きのエンジニアたちが集まるコミュニティーで、2024年の発足以来、connpassを中心に定期的にイベントを開催しています。

この勉強会の特徴は、アニメやラノベという身近なエンターテインメントコンテンツを、エンジニアリングの視点で深く掘り下げる点です。勉強会は主に平日夜に東京でオフライン開催し、毎回6から8名のスピーカーが「アニメから学んだエンジニアリング」をテーマに発表します。発表後には参加者全員で交流の時間を設け、「あのシーンはこう解釈できる」「うちの現場でも似たような経験があった」など、アニメをきっかけにした自然な会話が生まれ、参加者同士のつながりが深まっています。過去のイベントでは、『SHIROBAKO』から目指したい仕事人について語る発表や、『ポケモン』から学ぶコミュニケーションなど、多様な切り口でアニメとエンジニアリングの交差点を探求してきました。

これまでは勉強会で発表することをしていましたが、勉強会に参加したことがない方にもアニメから得た学びを表現することの楽しさを知ってほしいと思い、2025年2月から同人誌の執筆を企画しました。また、勉強会のスライドでは伝えきれないことまで詳細に表現したいという思いも込めています。そして、これらの学びを本という形で残したいという思いも込めています。2025年6月に開催された技術書典18では、第1冊目となる『エンジニアニメ Anthology Tech Book 1st Season』を頒布し、2025年10月に開催された第十二回技術書同人誌博覧会では、第2冊目となる『エンジニアニメ Anthology Tech Book 2nd Season』を頒布し、多くの方にご好評いただきました。本書は第3冊目として、さらに多様なアニメ作品から得られた学びをまとめています。

『エンジニアニメ Anthology Tech Book 1st Season』、『エンジニアニメ Anthology Tech Book 2nd Season』は、以下のURLからご購入いただけます。

[https://engineers-anime.booth.pm/](https://engineers-anime.booth.pm/)
